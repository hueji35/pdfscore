# PDFScore — 웹 악보 플레이어

PC, 폰, 태블릿 브라우저에서 악보를 보고 MIDI로 재생하는 웹앱입니다. 기기에 아무것도 설치하지 않습니다.
PDF나 이미지 악보도 **브라우저 안에서** 인식(OMR)해서 바로 보여 줍니다.

## 기능
- PDF / PNG / JPG 악보를 인식해서 MusicXML로 변환합니다. 인식은 기기 안에서 하며, 파일을 서버로 보내지 않습니다.
- MusicXML(.mxl/.musicxml/.xml)은 인식 과정 없이 바로 엽니다.
- 파트별 **👁 악보 표시** on/off: 끄면 그 파트가 악보에서 사라지고 다시 배치됩니다.
- 파트별 **🔊 소리** on/off, 음량 조절, 재생 악기 변경 (GM 128종 + 드럼)
- 재생할 때 커서가 따라가고 **자동 스크롤**됩니다. 악보를 탭하면 그 위치부터 재생합니다.
- 도돌이표, 1·2번 괄호, D.C./D.S./Coda를 펼쳐서 재생합니다.
- 템포 25~200%, 확대/축소, 💾 인식 결과를 MusicXML로 저장

## 쓰는 방법: 이 폴더를 웹에 올리기
폰·태블릿에서 열려면 이 폴더가 웹 주소로 열려야 합니다. 정적 호스팅 아무 곳에나 폴더를 통째로 올리면 됩니다.

| 호스팅 | 방법 | 비고 |
|---|---|---|
| **GitHub Pages** (권장) | 저장소를 만들어 폴더 내용을 올리고 Settings → Pages 켜기 | 무료. 파일당 100MB 제한 이내입니다(가장 큰 모델 94MB) |
| **Hugging Face Spaces** (Static) | Space를 만들고 폴더를 업로드 | 무료. 큰 파일도 문제없습니다 |

Netlify나 Cloudflare Pages는 파일당 용량 제한(약 10~25MB) 때문에 인식 모델을 올리기 어렵습니다.

한 번 올려 두면 PC, 폰, 태블릿 어디서든 그 주소로 접속해 쓸 수 있습니다.

### 집 PC에서 바로 쓰기 (호스팅 없이)
`start.bat`을 실행하면 PC가 잠시 웹 서버가 됩니다. 같은 Wi‑Fi의 폰·태블릿에서는 콘솔에 표시되는 `http://192.168.x.x:8000`으로 접속하면 됩니다. Python이 필요합니다.
MusicXML만 볼 거라면 `index.html`을 더블클릭해도 됩니다. 다만 브라우저 보안 정책 때문에 이렇게 열면 PDF/이미지 인식은 동작하지 않습니다.

## 악보 인식(OMR)에 대해
- 엔진은 [homr-web](https://github.com/jymen/homr-web)(homr의 브라우저 이식판)입니다. 인식 모델은 `models/` 폴더에 들어 있습니다.
- **처음 인식할 때** 모델을 내려받습니다. WebGPU 기기는 약 130MB, 그 밖의 기기는 약 180MB이고, 이후에는 브라우저에 저장된 것을 씁니다. 처음에는 Wi‑Fi에서 쓰기를 권합니다.
- 속도 (실측: PC + WebGPU, 오선 8줄짜리 악보 1쪽)
  - 페이지당 약 27초. 시간은 대부분 오선 한 줄마다 약 2.5초씩 드는 음표 읽기에 쓰이므로, 오선 줄이 많은 악보일수록 오래 걸립니다
  - 여러 페이지 PDF는 첫 페이지를 먼저 읽어 바로 보여 주고, 나머지는 두 페이지씩 동시에 읽습니다(3쪽 약 1분)
  - PC는 페이지를 열면 바로, 폰은 '열기'를 누르는 순간 인식 엔진을 미리 준비해 둡니다(모델 내려받기와 초기화를 미리 끝내 둠)
  - WebGPU가 없는 기기(호환 모드)는 PC에서도 페이지당 1분 반~2분이고, 폰은 이보다 오래 걸립니다
  - 진행 화면에 지금 쓰는 엔진(WebGPU / 호환 모드), 경과 시간, 남은 시간이 표시됩니다
- **인식 결과는 이 기기(브라우저)에 페이지별로 저장됩니다.** 같은 파일을 다시 열면 몇 초 만에 열리고, 중간에 취소하거나 창을 닫았다면 다음에 열 때 남은 페이지만 이어서 읽습니다
- 빠른 엔진이 기기에서 멈추면 자동으로 호환 모드(단일 스레드)로 바꿔 다시 인식하고, 그 설정을 기억합니다.
- 인식이 잘 되는 악보: 깨끗한 인쇄 악보, 300dpi 스캔, 똑바로 찍은 사진
- 인식이 어려운 악보: 손글씨, 흐린 사진, **타악기(드럼) 보표**, 가사가 많이 겹친 악보
- 악기 이름은 인식하지 않으므로 파트가 "파트 1, 2…"로 표시됩니다. 패널에서 재생 악기를 골라 주세요.
- 틀린 부분은 💾로 저장한 MusicXML을 MuseScore 등에서 고친 뒤 다시 열면 됩니다.

## 참고
- 악기 소리(SoundFont)는 처음 재생할 때 인터넷에서 내려받습니다(악기당 약 1~2MB). 오프라인이면 기본 신스음으로 재생합니다.
- 사용한 라이브러리: OpenSheetMusicDisplay(BSD-3), soundfont-player(MIT), homr-web(**AGPL-3.0**), onnxruntime-web(MIT), OpenCV.js(Apache-2.0), pdf.js(Apache-2.0).
  라이선스 파일은 `lib/` 폴더에 있습니다. homr-web이 AGPL이므로 이 앱을 공개 웹에 올려 다른 사람이 쓰게 할 때는 소스 코드도 공개해야 합니다. 이 폴더 자체가 소스이므로 함께 올리면 됩니다.
